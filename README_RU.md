# Расписание 8А — страница-заглушка

Это временная страница для подключения Web App в BotFather. Позже её можно заменить полноценным интерфейсом расписания.

## Публикация через GitHub Pages
1. Создай репозиторий на GitHub (например, `schedule-8a`).
2. Загрузи `index.html` в корень репозитория.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку `main` и папку `/(root)`, затем нажми **Save**.
6. Дождись публикации. GitHub покажет HTTPS-адрес страницы в разделе Pages.
7. В BotFather укажи этот адрес как URL Web App.

Важно: ссылка появится только после публикации на GitHub Pages. Сам файл не является публичным сайтом.
